# PetStore 宠物生活馆

静态原型站点，呈现宠物食品、玩具、居家、户外、周边等业务线与宠物视频/直播内容，配合粉红与浅蓝绿色的简洁设计风格。

## 项目结构
```
├── index.html          # 首页：大幅 Banner、业务模块分区、视频与 CTA
├── assets
│   ├── css
│   │   └── style.css   # 主题色、布局、组件样式与响应式设计
│   ├── js
│   │   └── main.js     # 移动端导航展开/收起与锚点平滑滚动
│   └── images          # 预留静态资源目录
```

## 本地预览
使用任意静态服务器即可，例如：
```bash
python -m http.server 8000
```
然后在浏览器访问 `http://localhost:8000`。
